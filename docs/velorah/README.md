# `/velorah` — шилэн (glassmorphic) кино hero

Ганц дэлгэцийн hero: бүтэн дэлгэцээр давтагдах клип, шилэн цэс,
Instrument Serif дэлгэцийн бичиг, гүн хөх суурь. Чимэглэлийн бөмбөлөг,
радиал градиент, хөшиг БАЙХГҮЙ — гүн гүнзгийг зөвхөн клип өгнө.

`/noir` (Elysium-ийн ногоон кино theme) -ийг ХӨНДӨӨГҮЙ — тусдаа route.

```
src/app/velorah/{page,layout}.tsx      — route (ISR 300s)
src/app/velorah/velorah.css            — палитр, liquid glass, анимэйшн
src/components/velorah/VelorahHero.tsx — server component (client JS = 0)
```

## Өнгө — `.velorah-page`-д хаалттай

Макетын HSL гурвалууд `velorah.css` дотор `.velorah-page`-д сууна:

| Хувьсагч | Утга |
| --- | --- |
| `--background` | `201 100% 13%` (гүн хөх) |
| `--foreground` | `0 0% 100%` |
| `--muted-foreground` | `240 4% 66%` |
| `--primary` / `--primary-foreground` | `0 0% 100%` / `0 0% 4%` |
| `--secondary` · `--muted` · `--accent` | `0 0% 10%` |
| `--border` · `--input` | `0 0% 18%` |

`globals.css`-ийн `@theme inline` нь `--color-background: hsl(var(--background))`
гэж холбоно. **`inline` учир** утилит нь хэрэглэх ГАЗАРТАА `var(--background)`-ыг
уншдаг — тиймээс `bg-background` / `text-muted-foreground` зэрэг нь
`.velorah-page`-ээс гадуур огт үйлчлэхгүй, сайтын цайвар theme-үүд аюулгүй.

⚠️ Бүрхүүл дээр `text-foreground` ЗААВАЛ байна: сайтын `body` нь брэндийн
ногоон `text-ink`-тэй тул үүнгүйгээр `<h1>`-ийн үндсэн өнгө ногоон болж
өвлөгддөг (зөвхөн `<em>`-үүд нь зөв гарна).

## Бичгийн фонт

Instrument Serif нь **кирилл үсэггүй** (latin, latin-ext). Тиймээс дэлгэцийн
стек нь `Instrument Serif → Playfair Display → Georgia → serif`: хөтөч үсэг
тус бүрээр буцдаг тул “Elysium” нь Instrument Serif-ээр, монгол бичвэр нь
Playfair-ээр гарна. Их бие — Inter.

⚠️ **`var(--font-instrument-serif)` хэрэглэж БОЛОХГҮЙ.** `next/font` нь тэр
хувьсагчийг ХОЁР гэр бүлийн жагсаалт болгодог:
`"Instrument Serif", "Instrument Serif Fallback"`. Сүүлийнх нь
`src: local(Times New Roman)` бөгөөд **unicode-range заагаагүй** — кирилл
үсэг бүр Playfair хүрэлгүй тэнд унана. Үр дүнд нь гарчиг Windows/macOS дээр
83.94% хэмжээтэй Times New Roman, Times байхгүй систем (Android) дээр
Playfair болж, **платформоос хамааран өөр** харагдана. `adjustFontFallback:
false` нь Next 16.2.9-д үйлчилсэнгүй (build-ийн гаралтаас шалгасан), тиймээс
`velorah.css` дотор гэр бүлийн нэрийг **шууд** бичсэн. Google-ийн фонтын
@font-face нэр хэшлэгддэггүй тул энэ найдвартай.

Дэлгэцийн хоёр фонт нь root layout-д БИШ, `app/velorah/layout.tsx`-д
тодорхойлогдоно — `next/font` нь фонтыг импортолсон сегментэд л
`<link rel=preload>` гаргадаг. Ингэснээр `/`, `/noir`, `/news` дээрх
фонтын preload 34-өөс 31 болж буурсан.

## Агуулга — бүгд админаас

`/admin/site` → **Нүүр дэлгэц** → “Шилэн кино hero (/velorah)”:

| Талбар | Юу удирдах |
| --- | --- |
| `hero.cinema.logo` | Толгойн богино wordmark (хоосон бол `brand.line`) |
| `hero.cinema.mark` | Дээд индекс. ⚠️ `®` нь БҮРТГЭГДСЭН барааны тэмдгийг илэрхийлнэ — брэнд бүртгэлгүй бол хоосон болго |
| `hero.cinema.headline` | Гол өгүүлбэр. `*од*` хашсан хэсэг бүдэг өнгөөр ялгарна |
| `hero.cinema.video` | Бүтэн дэлгэцийн клип (дотоод зам эсвэл `https://…`) |
| `hero.cinema.poster` | Клип тоглохоос өмнөх кадр. **Өгөгдмөл нь хоосон** — сангийн экстерьер зураг бүр тод (135–197/255) тул хөх композицид зохихгүй. Өөрийн клипийн эхний кадраар дүүргэнэ үү: iOS-ийн эрчим хүч хэмнэх горим autoplay-г хаадаг |

Тайлбар бичвэр (`hero.sub`), цэс (`nav.items`), товчны нэр (`nav.ctaLabel`),
брэнд (`brand.line`) нь үндсэн сайттай ХАМТ удирдагдана. Админ хадгалахад
`/velorah` мөн revalidate хийгдэнэ.

Hero нь ганц дэлгэц тул цэсний `#зангуу`-нууд үндсэн сайт руу (`/#about` г.м.)
заана — үхсэн холбоос үлдэхгүй.

## Макетаас ЗӨРСӨН гурван зүйл (бүгд шалтгаантай)

1. **`tracking-[-2.46px]` нь зөвхөн `md:`-д.** Энэ утга нь 96px (`text-8xl`)
   хэмжээнд зориулагдсан; жижиг дэлгэцэд ижил утга нь үсэг хоорондын зайг
   ~5% болгож монгол бичвэрийг наалддаг. `sm:` дээр `-1.8px`, доор нь `-1px`.
2. **`mask` (prefix-гүй) нэмсэн.** Макет зөвхөн `-webkit-mask`-ийг өгсөн;
   үүнгүйгээр Firefox дээр `mask-composite: exclude` ажиллахгүй тул шилэн
   ирмэг нь ирмэг биш, БҮТЭН цагаан дүүргэлт болж харагдана.
3. **`-webkit-backdrop-filter` нь стандартаасаа ӨМНӨ.** Эсрэгээр бичихэд
   минификатор хоёуланг нэгтгээд prefix-гүй хувилбарыг хаядаг — Firefox
   блургүй үлдэнэ (build-ийн гаралтаас баталгаажсан).

`pt-32 pb-40 py-[90px]` гурвуулаа макетын дагуу үлдсэн: Tailwind-ийн дүрмээр
`pt`/`pb` нь `py`-г дардаг тул бодит утга нь `128px / 160px` (шалгасан).

## Шалгасан зүйлс

`1487×1058`, `1440×720`, `430×932` дээр Playwright-аар: клип бүтэн дэлгэц
(`1487×1058@0,0`, `object-fit: cover`, `z-index: 0`), `h1` = 96px /
`letter-spacing: -2.46px` / `line-height: 91.2px`, суурь = `rgb(0,43,66)`,
бүдэг бичиг = `rgb(165,165,172)`, `backdrop-filter: blur(4px)`,
`::before` padding `1.4px` + `mask-composite: exclude`. 720px өндөртэй
дэлгэцэд ч юу ч тасрахгүй.
