# Elysium Residence — Захиалагчаас авах asset-ийн жагсаалт ба спек

`/final` хуудас бэлэн боловч одоо **placeholder** ашиглаж байна. Доорх asset-уудыг авмагц placeholder-уудыг шууд солино.
Format товч: **WebP/JPG** = зураг, **MP4 (H.264) + WebM** = видео, **woff2** = фонт.

---

## 1. Intro / танилцуулга видео ⭐ (хуудасны дунд тоглоно)
| Зүйл | Спек |
|---|---|
| **Үүрэг** | Хуудасны **дунд хэсэгт** (ELYS давуу талын дараа) full-width тоглох төслийн танилцуулга видео. Hero-гийн "видео үзэх" товч энэ рүү аваачна. |
| **Формат** | `.mp4` (H.264, AAC) **+** `.webm` (VP9) — хоёулаа |
| **Харьцаа / нягт** | 16:9, **1920×1080** (4K байвал илүү) |
| **Урт** | 30–90 секунд |
| **Жин** | Шахсан **≤ 20 MB** (вэбэд хурдан) |
| **Дуу** | Click хийж тоглоно (анх дуугүй) |
| **Нэмэлт** | **Poster зураг** (видео эхлэхээс өмнө харагдах, 1920×1080 JPG) заавал |
