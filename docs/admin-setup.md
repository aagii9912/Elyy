# Админ — Тохируулгын заавар

Энэ баримт нь `/admin` хэсэг (сайтын контентын засварлагч + эвентийн
landing page generator)-ыг production-д (Vercel) ажиллуулах тохиргоог
тайлбарлана.

## Товч тойм

- **`/admin`** — нэг нууц үгээр хамгаалагдсан удирдлагын самбар.
- **`/admin/site` → 🎨 Дизайн / Өнгө** — **сайтын дэвсгэр өнгө, градиент,
  дэвсгэр зураг.** Глобал палитр + хэсэг тус бүрийн дэвсгэрийг тусад нь
  тохируулна (доор 5.0-ыг үз).
- **`/admin/site`** — **үндсэн сайтын (`elysium.mn/`) бүх текст, зургийн
  засварлагч.** Толгой цэс, hero, бүх хэсгийн гарчиг/тайлбар, өрөөний
  типүүд, өмнөх төслүүд, зургийн цомог, байршил, холбоо барих, менежерүүд,
  FAQ, хөл хэсэг, чатбот, SEO мета — бүгд эндээс засагдана.
- **`/admin/news`** — **мэдээ / нийтлэлийн удирдлага.** Нийтлэл нэмэх, засах,
  зураг оруулах, ноорог ↔ нийтлэх. Public хаяг: `elysium.mn/news` (жагсаалт),
  `elysium.mn/news/<slug>` (дэлгэрэнгүй). Толгой болон хөлний цэсэнд
  “Мэдээ” холбоос автоматаар байрлана.
- **Эвент үүсгэх** → `/admin` дээрээс нэр өгөөд үүсгэнэ. Public хаяг нь `elysium.mn/<slug>`.
- **Lead capture** — эвентийн маягт нь одоо байгаа `/api/contact` → Google Sheet рүү очно.
  Sheet-д `Эх сурвалж = event/<slug>`, `Эвент = <нэр>` гэж бичигдэнэ.
- **Хадгалалт** — Supabase (Postgres + Storage). Тохируулаагүй бол локалд файлаар ажиллана.

## 1. Локал хөгжүүлэлт (Supabase-гүйгээр)

Юу ч тохируулахгүйгээр шууд ажиллана:

```bash
npm run dev
```

- Нээх: `http://localhost:3000/admin`
- Өгөгдөл: `.data/events.json`, `.data/site.json`, `.data/news.json`,
  зураг: `public/uploads/` (git-д орохгүй).
- `ADMIN_PASSWORD` тохируулаагүй тул нэвтрэлт идэвхгүй (локалд зүгээр).

> ⚠️ Локал горим зөвхөн хөгжүүлэлтэд. Vercel дээр файл систем read-only тул
> эвент/зураг **хадгалагдахгүй** — production-д заавал Supabase хэрэгтэй.

## 2. Supabase тохируулах (production)

### 2.1 Project + хүснэгт

1. [supabase.com](https://supabase.com) дээр үнэгүй project үүсгэ.
2. **SQL Editor** → доорхыг ажиллуул:

Хамгийн хялбар нь **`docs/supabase-init.sql`**-ийг бүхэлд нь paste хийж
ажиллуулах (idempotent — дахин ажиллуулж болно). Гар аргаар хийвэл:

```sql
create table if not exists public.events (
  id uuid primary key,
  slug text unique not null,
  name text not null,
  status text not null default 'draft',
  content jsonb not null,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index if not exists events_slug_idx on public.events (slug);

-- Үндсэн сайтын контент — ганц мөр (id = 'main').
create table if not exists public.site_content (
  id text primary key,
  content jsonb not null,
  updated_at timestamptz not null default now()
);

-- Мэдээ / нийтлэл.
create table if not exists public.news (
  id uuid primary key,
  slug text unique not null,
  title text not null,
  excerpt text not null default '',
  cover text not null default '',
  tag text not null default '',
  date text not null default '',
  body text not null default '',
  status text not null default 'draft',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index if not exists news_slug_idx on public.news (slug);

-- RLS-ийг асаана. Бүх хандалт service_role key-ээр (server талаас) явна.
alter table public.events enable row level security;
alter table public.site_content enable row level security;
alter table public.news enable row level security;
```

> Тайлбар: Апп нь зөвхөн **service role key**-ээр (сервер талаас) хандана.
> Тиймээс public policy шаардлагагүй — RLS асаалттай байхад аюулгүй.

### 2.2 Storage bucket (зураг)

1. **Storage** → **New bucket** → нэр: `elysium-media`, **Public** сонголтыг ✓.
   (Public bucket — зургийн URL landing page дээр шууд харагдана.)

> Bucket байхгүй бол эхний зураг байршуулах үед сервер өөрөө public bucket
> үүсгэхийг оролдоно. Зураг байршуулах ажиллаж байгаа эсэхийг `/admin` дээрх
> **Зураг хадгалалт → Шалгах** товчоор шалгаж болно.

### 2.3 API түлхүүр

**Project Settings → API** хэсгээс:

- `Project URL` → `SUPABASE_URL`
- `service_role` secret → `SUPABASE_SERVICE_ROLE_KEY`  ⚠️ нууц, зөвхөн серверт.

## 3. Environment хувьсагч (Vercel)

Vercel → Project → **Settings → Environment Variables**:

| Нэр | Утга |
| --- | --- |
| `ADMIN_PASSWORD` | Админд нэвтрэх нууц үг |
| `ADMIN_SESSION_SECRET` | `openssl rand -hex 32` (заавал биш) |
| `SUPABASE_URL` | Supabase Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role secret |
| `SUPABASE_MEDIA_BUCKET` | `elysium-media` (заавал биш) |

Локалд туршихын тулд `.env.local`-д мөн адил нэмж болно.

## 4. Google Sheet — Эвент багана

Lead-ийн мөр одоо **7 баганатай**:

```
Огноо | Нэр | Утас | И-мэйл | Мессеж | Эх сурвалж | Эвент
```

Sheet-ийн эхний мөрөнд гарчгаа тааруулж (сонголтоор) нэмээрэй. Тохируулга
өөрчлөх шаардлагагүй — шинэ багана автоматаар бичигдэнэ.

## 5. Ашиглах урсгал

### 5.0 Дизайн — дэвсгэр өнгө, градиент, зураг

`/admin/site` → зүүн талын **🎨 Дизайн / Өнгө**.

**Палитр.** 7 үндсэн өнгө (хуудасны суурь, карт, үндсэн бичиг, бүдэг бичиг,
тодруулга, гүн тодруулга, кино хөшиг). Эдгээр нь сайтын БҮХ хэсэгт нэг дор
үйлчилнэ. Дээр нь **бэлэн палитр** (Mono / Гүн ногоон / Шөнө / Цаас) нэг
товчоор солино. Талбар бүрийн доор **тодролын харьцаа** (WCAG) харагдана —
шар/улаан бол уншигдахгүй болж байна гэсэн үг.

**Хэсэг тус бүрийн дэвсгэр.** Толгой, hero, ELYS, өрөөний сонголт, FAQ,
хөл … нийт **15 хэсэг** тус бүрийг дарж дөрвөн төрлийн дэвсгэрээс сонгоно:

| Төрөл | Юу хийдэг вэ |
|---|---|
| **Токен** | Дизайн системийн нэрлэсэн өнгө. `Өгөгдмөл` = кодод бичсэн өнгө, юу ч өөрчлөгдөхгүй |
| **Өнгө** | Нэг тодорхой өнгө (color picker эсвэл hex) |
| **Градиент** | Шугаман / төвөөс / эргэлдэх · өнцөг · 2–8 өнгөний зогсоол |
| **Зураг** | Зураг оруулах (эсвэл хаягаар) · байрлал, хэмжээ, давталт, parallax, бүдгэрүүлэлт |

Дээр нь хэсэг бүрд:

- **Хөшиг** — дэвсгэр дээр давхарлах өнгө + хүч (0–100%). Зураг дээр бичиг
  уншигдахгүй бол үүнийг нэмнэ.
- **Бичгийн өнгө** — `Гэрэлтэй дэвсгэр` (бараан бичиг) / `Хар дэвсгэр`
  (цагаан бичиг) / `Авто`. Дэвсгэрээ хартай болгосон бол **заавал**
  `Хар дэвсгэр` болгоно, эс бөгөөс бичиг уншигдахгүй.
- **Урьдчилан харах** цонх — хадгалахаас өмнө үр дүнг шууд харна.

> **Цагаан карт өөрөө шийднэ.** Хэсгийн дэвсгэрийг хартай болгоход дотор нь
> байгаа цагаан карт, pop-up, маягтын бичиг **бараан хэвээр** үлдэнэ —
> тэдгээр нь өөрсдийн дэвсгэрт тааруулж автоматаар шийдэгддэг. Тиймээс
> зөвхөн хэсгийн үндсэн бичиг (гарчиг, тайлбар, жагсаалт) эргэнэ.

**Санамж:** Hero болон «01 · Ерөнхий төлөвлөлт» хэсгийн дэвсгэр дээр
бичлэгийн кадрууд тоглодог тул тэдний дэвсгэр өнгө нь зөвхөн кадр
ачаалагдах хүртэл харагдана.

### 5.1 Үндсэн сайтын текст засах

1. `/admin` → **Сайтын контент** (эсвэл шууд `/admin/site`).
2. Зүүн талаас хэсгээ сонгоод талбаруудаа засна.
3. Жагсаалттай хэсгүүдэд (өрөөний тип, төсөл, FAQ, менежер, ойролцоох
   цэг, сошиал холбоос г.м.) мөр **нэмэх / зөөх (↑↓) / устгах (✕)** боломжтой.
4. Зурагтай талбарт **Зураг оруулах** → Supabase Storage (эсвэл локалд
   `public/uploads/`) руу байршуулж URL-ыг автоматаар холбоно.
   Талбар бүр өөрийн **санал болгох хэмжээ, харьцааг** доороо бичиж
   харуулна (ж: «Санал болгох 675×900px (3:4)») — оруулсан зураг тухайн
   талбарын хэмжээ рүү browser дээр автоматаар багасна, том эх файлыг
   гараар жижигрүүлэх шаардлагагүй.
   **Брэнд & холбоо** хэсгийн *Онлайн танилцуулга (PDF)* талбарт
   **Файл хавсаргах** дарж PDF-ээ шууд оруулна — толгой дэх «Танилцуулга
   татах» товч болон хөл хэсгийн холбоос хоёулаа автоматаар шинэ файл руу
   чиглэнэ. Зураг browser дээр шахагдаж жижигрэх ба ~3.5MB-аас том файл
   (танилцуулга ихэвчлэн тийм) серверээр дамжихгүй, Storage руу **шууд**
   илгээгдэнэ (Vercel-ийн хүсэлтийн биеийн хязгаарыг тойрно).
5. **Хадгалах** → өөрчлөлт нийтийн сайт дээр шууд харагдана
   (сервер тал `/` хуудсыг дахин үүсгэнэ).
6. Санамсаргүй эвдвэл **“Энэ хэсгийг өгөгдмөл рүү буцаах”** товчоор
   тухайн хэсгийг кодон дахь анхны утга руу нь буцаана (Хадгалах хүртэл
   эцэслэгдэхгүй).

> Хадгалаагүй өөрчлөлттэй үед хуудсыг хаах гэвэл браузер анхааруулна.
> Хадгалаагүй бол сайт дээр юу ч өөрчлөгдөхгүй.

**Кодын өгөгдмөл vs хадгалсан утга.** `src/lib/site-content.ts` дэх өгөгдмөл нь
зөвхөн хадгалаагүй талбаруудад үйлчилнэ. Нэгэнт `/admin/site` дээр засаж
хадгалсан бол хадгалсан утга нь өгөгдмөлийг дардаг — өөрөөр хэлбэл кодод
шинэ текст бичсэн ч тэр хэсэгт гарч ирэхгүй. Хэсгийн жагсаалтад **шар цэг**
байвал тухайн хэсэг өгөгдмөлөөс өөрчлөгдсөн гэсэн үг.

Кодын шинэ текстийг татахдаа:

- нэг хэсгийг бүхэлд нь → **“Өгөгдмөл рүү буцаах” → “Хадгалах”**
  (тухайн хэсгийн бусад гар засвар устана), эсвэл
- зөвхөн шаардлагатай талбарыг гараар засна.

### 5.1.1 Захиалагчийн PDF засварыг нэг дор тавих

`scripts/apply-site-fixes.mjs` нь PDF тэмдэглэлд заасан талбаруудыг
(толгой цэсний шошго, hero-гийн дэд текст, 03-р бүлгийн гарчиг + 4 spec
карт, борлуулалтын баг + цагийн хуваарь) **зөвхөн тэр талбаруудад нь**
шинэчилнэ — бусад засварыг хөндөхгүй, дахин ажиллуулж болно.

```bash
# 1) Юу өөрчлөгдөхийг харах (юу ч бичихгүй)
node scripts/apply-site-fixes.mjs https://elysium.mn '<ADMIN_PASSWORD>'

# 2) Бодитоор тавих
node scripts/apply-site-fixes.mjs https://elysium.mn '<ADMIN_PASSWORD>' --apply
```

### 5.2 Мэдээ нэмэх

1. `/admin` → **Мэдээ** (эсвэл шууд `/admin/news`).
2. Гарчиг бичээд **+ Мэдээ нэмэх** → засварлагч нээгдэнэ (slug автоматаар үүснэ).
3. Огноо, шошго, нүүр зураг, товч танилцуулга, агуулгаа бөглөнө.
   Агуулгад: хоосон мөр = шинэ догол мөр, `## ` = дэд гарчиг, `- ` = жагсаалт,
   `![тайлбар](зургийн-хаяг)` = нийтлэлийн дунд орох зураг.
   Зургийг гараар бичих шаардлагагүй — агуулгын доорх **Зураг оруулах**
   товчийг дарахад курсорын байрлалд автоматаар нэмэгдэнэ.
   Доор нь урьдчилсан харагдац шууд харагдана.
4. **Урьдчилж үзэх** → `/news/<slug>?preview=1` (ноорог хэвээр).
5. **Нийтлэх** → `/news` жагсаалтад болон `/news/<slug>` дээр нээлттэй болно.

> `/news` хуудасны бэлэн текст (гарчиг, тайлбар, цэсний нэр г.м.)-ийг
> `/admin/site` → **Мэдээ (хуудасны текст)** хэсгээс засна.

### 5.3 Эвент үүсгэх

1. `/admin` → нэвтрэх.
2. Нэр өгөөд **Эвент үүсгэх** → засварлагч нээгдэнэ.
3. Hero текст/зураг, хэсгүүд (нэмэх / дараалал өөрчлөх / устгах), маягт, өнгө тохируулах.
4. **Урьдчилж үзэх** (ноорог) → `/<slug>?preview=1`.
5. **Хэвлэх** → эвент нийтэд `elysium.mn/<slug>` дээр нээлттэй болно.
6. Бүртгэлүүд Google Sheet-д `event/<slug>` эх сурвалжтайгаар ирнэ.

## 6. Санамж

- Slug давхцвал автоматаар `-2`, `-3` залгана. `admin`, `api`, `news`, `final`,
  `mono` зэрэг системийн нэрсийг ашиглах боломжгүй.
- Мэдээ нэмэх/засахад `/news` болон тухайн нийтлэлийн хуудас автоматаар
  шинэчлэгдэнэ (slug сольсон ч хуучин зам нь цэвэрлэгдэнэ).
- Ноорог эвентийг зөвхөн `?preview=1`-тэй үзнэ, хайлтын системд индекслэгдэхгүй.
- Сайтын контентын **өгөгдмөл утга** нь `src/lib/site-content.ts` дотор.
  Хадгалсан өгөгдөл дээр давхарлагддаг тул:
  - `site_content` мөр байхгүй/устсан ч сайт өгөгдмөл текстээрээ ажиллана,
  - код дээр шинэ талбар нэмэхэд хуучин хадгалсан контент эвдрэхгүй,
  - хадгалахын өмнө танихгүй талбар, буруу төрлийг сервер тал цэвэрлэнэ.
