# `/noir` — Elysium-ийн кино маягийн харанхуй theme

Хэмжсэн 1487×1058 макетын гео­метрийг ЯГ хадгалж, өнгийг нь бүхэлд нь
Elysium-ийн брэндийн палитр (гүн ногоон · цөцгий · лайм) руу шилжүүлсэн
**бүрэн динамик** theme. Хар өнгө, ягаан, гэрлийн бөмбөлөг, чимэглэлийн
градиент БАЙХГҮЙ — hero-гийн гол дүрслэл нь бүтэн дэлгэцээр давтагдах клип.

| Хүргэлт | Зам | Тайлбар |
| --- | --- | --- |
| Амьд theme | `/noir` | Next.js route. Бүх текст, зураг, клип, өнгө нь `/admin/site`-аас удирдагдана. **Эх хувилбар нь энэ.** |
| Бие даасан файл | `docs/noir/index.html` | Build хэрэггүй нэг файл (85 KB). Браузераар шууд нээнэ. Контент нь өгөгдмөл утгуудын хувилбар (snapshot). |

Бие даасан файлыг дахин үүсгэх:

```bash
node scripts/build-noir-preview.mjs
```

CSS нь `src/app/noir/noir.css`-ЭЭС уншигддаг тул theme-ийн өнгө/хэмжилт
өөрчлөгдвөл дээрх командыг дахин ажиллуулахад л хангалттай.

---

## Хэмжээний систем

```css
--u:  calc(100dvh / 1058);   /* макетын 1px — ӨНДРӨӨС хамаарна */
--uw: calc(100vw / 1487);
--h:  clamp(--u, --u*.65 + --uw*.35, --u*1.16);   /* бичиг өргөн дэлгэцэд +16% хүртэл */
```

Босоо хэмнэл дэлгэцээ үргэлж дүүргэнэ: цэс 51u, гарчиг 230.5u, түншийн
зурвас 985u, суурь 1058u. Босоо дэлгэцэд (`max-aspect-ratio: 11/10`)
`--u` нь `--m: min(100vw/430, 1.34px)` руу шилжиж, hero нь урсгал
байрлал руу орно; таблетын хувьд `min(100vw/860, 100vh/760, 1.25px)`.

**Гарчиг ба тайлбарын хоорондох зай** нь макетын утгаар (28h / 28.5h)
барина, гэхдээ `.nv-copy` дотор УРСГАЛ байрлалтай — админ урт текст
бичихэд товчтой давхцахгүй.

## Өнгө — бүгд админаас

`noir.css` нь өөрийн гэсэн тогтмол өнгө барихгүй, `/admin/site → Дизайн`-ийн
палитраас гаралтай:

| Theme токен | Эх сурвалж | Өгөгдмөл |
| --- | --- | --- |
| `--nv-deep` | палитрын `film` → `--color-charcoal` | `#16280f` |
| `--nv-void` | `--nv-deep`-ийн 52% + хар | ≈ `#0a1207` |
| `--nv-accent` | палитрын `accent` → `--color-lime` | `#b4d656` |
| `--nv-accent-deep` | палитрын `accentDeep` → `--color-moss` | `#3f6a33` |
| `--nv-ink` / `--nv-pill` | брэндийн цөцгий | `#f4f8e6` / `#fafee5` |

Палитраа сольмогц клипийн grade, самбарын бүрхүүл, хөшиг бүхэлдээ дагаж
эргэнэ (жишээ: `film`-ийг ягаан болговол хуудас шөнийн ягаан болно).

Хэсэг бүр `data-bg="<id>"` + `data-tone`-той тул админ **хэсэг тус бүрийн**
дэвсгэрийг (өнгө / градиент / зураг) сольж чадна — `buildThemeCss` нь
`:is(.mono-page,.noir-page)`-д зориулж дүрмээ бичдэг. `tone: "light"`
сонговол палитр бүхэлдээ эргэж (бичиг гүн ногоон, товч бараан), дэвсгэрээ
сонгоогүй байсан ч уншигдахуйц цайвар суурь автоматаар орно.

## Бүтэц


| Секц | `data-bg` | Онцлог |

| Hero | `hero` | Бүтэн дэлгэцийн клип + хэмжсэн ирмэгийн бүдгэрэлт, доор нь түншийн зурвас (`equip.equipment.items`-ийн эхний 4 брэнд) |
| 01 Ерөнхий төлөвлөлт | `stats` | Дэлгэц дээр гармагц тоологдох тоонууд |
| 02 ELYS | `elys` | Дэлгэгддэг 4 самбар (hover/click) |
| 03 Барилгын бүтэц | `equip` | Харагдах үед л тоглох клипүүд |
| Өрөөний сонголт | `apartments` | B1/B2 шүүлтүүр, хөвүүлэхэд гарах төлөвлөгөө, бүтэн дэлгэцийн үзэгч |
| Зургийн цомог | `gallery` | 2×2 том кадр + lightbox (←/→/Esc) |
| Төсөл хэрэгжүүлэгч | `developer` | Хэвтээ гүйдэг зурвас |
| Байршил | `location` | Төсөл/оффис таб, харанхуйд тааруулсан газрын зураг |

| FAQ | `faq` | Аккордеон |

## Хөдөлгөөн

`prefers-reduced-motion: no-preference` үед л ажиллана; easing
`cubic-bezier(.22,1,.36,1)`. Нэвтрэх дараалал: тэмдэг/цэс/товч 0.8s →
гарчиг 0.06s → тайлбар 0.14s → товчнууд 0.22s → түншийн зурвас 0.34s.
Доод секцүүд нэг IntersectionObserver-оор `[data-rise]` авч гарч ирнэ
(`NoirMotion`) — секц бүрд GSAP ачаалахгүй.

## Бичгийн фонт

Амьд theme нь брэндийн **Gilroy**-г (`--font-gilroy`) хэрэглэнэ. Бие даасан
файл нь `src/fonts/gilroy/*.otf`-ыг замаар нь ачаалж, боломжгүй бол
Google Fonts-ийн **Manrope** руу зөөлөн буцна.
