# Тоноглолын зургийн харагдац — дизайны эх файлууд

`03 · Үндсэн бүтээц`-ийн тоноглолын жагсаалтад (CTA-гийн pop-up,
`src/components/ui/integration-grid.tsx`) бүтээгдэхүүний зураг хэрхэн
суух тухай дизайн.

**Сонгосон чиглэл:** мөр жагсаалт, зураг БАРУУН талд, өөрийн хайрцаггүй,
картын дэвсгэр рүү уусан ордог (`mask-image` градиент).

| Файл | Юу вэ | Хуудас |
|---|---|---|
| `Main.dc.html` | B+ · 2 багана, зураг баруун талд уусна (санал болгосон) | 1 |
| `Wide.dc.html` | B+ · Өргөн мөр, картгүй, зөвхөн зураас | 1 |
| `Mobile.dc.html` | Гар утасны хувилбар | 1 |
| `RowsBoxed.dc.html` | Өмнөх B — зураг зүүн талд, хайрцагт | 2 |
| `Current.dc.html` | Сайт дээр одоо байгаа (16:10 тайралт) | 2 |
| `canvas.json` | Байрлал, хуудсууд, тэмдэглэлүүд |  |

Өнгө, хэмжээ, радиус бүгд одоогийн кодоос авсан (`globals.css`,
`integration-grid.tsx`, `MonoModal.tsx`). Карт доторх дүрснүүд нь
жинхэнэ бүтээгдэхүүний зургийн ОРЛУУЛАГЧ.

Засах: эдгээр файлыг засаад `/design` skill-ээр дахин угсарч нийтэлнэ
(угсарсан `.html` нь git-д ордоггүй).
