# Тоноглолын зургийн харагдац — дизайны эх файлууд

`03 · Үндсэн бүтээц`-ийн тоноглолын жагсаалтад (CTA-гийн pop-up,
`src/components/ui/integration-grid.tsx`) бүтээгдэхүүний зураг хэрхэн
суух тухай 3 санал.

| Файл | Юу вэ |
|---|---|
| `Main.dc.html` | Санал A · Бүтээгдэхүүний тавцан (санал болгосон) |
| `Rows.dc.html` | Санал B · Мөр жагсаалт |
| `Bleed.dc.html` | Санал C · Бүтэн зураг + хөшиг |
| `Current.dc.html` | Одоогийн харагдац — зэрэгцүүлэхэд |
| `Mobile.dc.html` | Санал A гар утсан дээр |
| `canvas.json` | Байрлал, тэмдэглэлүүд |

Өнгө, хэмжээ, радиус бүгд одоогийн кодоос авсан (`globals.css`,
`integration-grid.tsx`, `MonoModal.tsx`). Карт доторх дүрснүүд нь
жинхэнэ бүтээгдэхүүний зургийн ОРЛУУЛАГЧ.

Засах: эдгээр файлыг засаад `/design` skill-ээр дахин угсарч нийтэлнэ
(угсарсан `.html` нь git-д ордоггүй).
