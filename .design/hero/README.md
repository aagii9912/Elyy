# Hero — типографи

`src/components/mono/MonoHero.tsx` хэсгийн бичгийг тансаг харагдуулах дизайн.
Фонт ӨӨРЧЛӨГДӨХГҮЙ — бүх хувилбар Gilroy (сайтад байгаа жингүүд) дээр.

**Одоогийн 8 асуудал** (canvas дээрх «яагаад хямд харагддаг вэ» тэмдэглэл):
төвлөрсөн байрлал · том үсэг дээрх ХАСАХ tracking · бичгийн сүүдэр ·
дунд жин 500 · ханасан лайм kicker · 74px даруухан гарчиг · 14px bold товч ·
кадрын хоосон зүүн тал ашиглагдаагүй.

Артбоард бүрийн дээрх «Кадар» (frame) сонголт ар талын кадрыг өдөр / үдэш /
алтлаг гэж сольж, бичиг клипийн бүх үед уншигдаж буйг шалгана.

B · Didone хувилбар шинэ фонт шаарддаг байсан тул хасагдсан.

Артбоард бүр Gilroy 200–600 жинг (латин + кирилл дэд олонлог, woff2) өөр
дотроо `@font-face`-аар авч явдаг — канвас дээр жинхэнэ фонт харагдана.

Засах: эдгээр файлыг засаад `/design` skill-ээр дахин угсарч нийтэлнэ.
