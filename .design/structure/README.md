# 03 · Барилгын бүтэц — гол мессеж

`src/components/ui/portrait-showcase.tsx` (MonoEquip ашигладаг) хэсгийн
бичвэрийн шатлал, байрлалыг засах дизайн.

**Шатлал** — мессеж өгөгдөлд аль хэдийн байсан, зөвхөн буруу хэмжээтэй байв:

| Талбар | Одоо | Байх ёстой |
|---|---|---|
| `equip.title` («Барилгын бүтэц» — ангиллын нэр) | display 64px | kicker |
| `item.title` («Бүрэн цутгамал хийцлэл» — МЕССЕЖ) | доод зурваст 14px | **display** |
| `item.body` (тайлбар) | баруун дээд буланд хөвсөн 14px | **зүүн доод талд бүтнээрээ** |

**Текст, өгөгдлийн бүтэц юу ч өөрчлөгдөхгүй** — өгүүлбэр таслалаа ч
алдалгүй бүтнээрээ үлдэнэ.

| Файл | Юу вэ | Хуудас |
|---|---|---|
| `Main.dc.html` | A · Өгүүлбэр доод зүүн, доор нь thumbnail (санал болгосон) | 1 |
| `Beside.dc.html` | B · Өгүүлбэр ба thumbnail нэг мөрөнд, зүүн талдаа | 1 |
| `Split.dc.html` | C · Өгүүлбэр зүүн доод, thumbnail баруун доод | 1 |
| `Current.dc.html` | Одоогийн харагдац | 1 |
| `Mobile.dc.html` | Гар утас · A | 1 |
| `Slide2.dc.html` | Систем 02-р слайдад (Veka Softline) | 2 |
| `Slide3.dc.html` | Систем 03-р слайдад (Yaret фасад) | 2 |
| `structure.webp` | Дэвсгэр кадр |  |
