# 03 · Барилгын бүтэц — гол мессеж

`src/components/ui/portrait-showcase.tsx` (MonoEquip ашигладаг) хэсгийн
бичвэрийн ШАТЛАЛЫГ засах дизайн.

**Асуудал:** display гарчиг нь «Барилгын бүтэц» гэсэн ШОШГО байсан;
худалдан авагчид чухал зүйл («Газар хөдлөлтийн 8 баллд тэсвэртэй») нь
14px догол мөрөнд, баруун дээд буланд хөвж байв.

**Шийдэл:** «Барилгын бүтэц» kicker болж, display хэмжээг слайдын гол
давуу тал эзэлнэ.
